# 终端交互体验 (chat.py)

为了让学习者直观感受大语言模型的**自回归生成（Autoregressive Generation）**与**流式输出（Streaming Output）**过程，项目提供了命令行交互工具 `chat.py`。

## 🌟 启动方式

在模型训练完成后（确认已存在 `result/model.pt`），直接运行：

```bash
python chat.py
```

终端将显示如下启动面板：

```text
============================================================
🤖 迷你基座语言模型 - 终端交互体验
============================================================
• 模型参数量: 26,727 个
• 词表大小: 199 个字符
• 当前设置: 生成长度=60, 温度=0.8

💡 指令说明:
  - 输入提示词直接回车，模型将进行续写
  - 输入 ':temp 0.5' 调整采样温度 (推荐 0.2 ~ 1.0)
  - 输入 ':len 80' 调整生成长度
  - 输入 ':vocab' 查看字符表中的字符
  - 输入 'exit' 或 'quit' 退出交互
------------------------------------------------------------
💡 推荐体验的开头: '问题：'、'雨停了，'、'清晨，'、'种子'、'文字模型'
============================================================

📝 请输入提示词 > 
```

---

## ⌨️ 核心功能与交互指令

### 1. 实时文本续写 (流式打字机)
输入在语料中出现过的词句片段，按回车即可看到模型像打字机一样逐字吐出字符：

```text
📝 请输入提示词 > 雨停了，
🤖 模型输出: 雨停了，院子里的石板还有水光。小猫沿着墙边走，闻了闻一片落叶。
```

### 2. 动态调节采样温度 (`:temp <float>`)
- **低温 (`:temp 0.2`)**：输出确定性极高，模型倾向于选择概率最大的下一个字符，严格重现训练语料。
- **高温 (`:temp 1.2` 或更高)**：增加输出多样性与随机性，更容易产生字符组合发散。

```text
📝 请输入提示词 > :temp 0.3
✅ 采样温度已调整为: 0.3
```

### 3. 动态调节生成长度 (`:len <int>`)
控制模型在单次提示词后最多自回归生成多少个新字符：

```text
📝 请输入提示词 > :len 100
✅ 生成长度已调整为: 100
```

### 4. 查阅内置字符表 (`:vocab`)
字符级分词器仅支持训练集中出现过的字符。若不确定某个字是否可用，输入 `:vocab` 查看：

```text
📝 请输入提示词 > :vocab
字符表包含的字符如下:
\n   、 。 一 上 下 不 ... 雨 院 需 露 青 风
```

### 5. 未见字符友好拦截
如果你输入的提示词包含未在语料中出现过的字符（例如输入“人工智能”或“苹果”），`chat.py` 不会崩溃，而是会精准提示拦截：

```text
📝 请输入提示词 > 人工智能是什么？
⚠️ 提示词中包含未见过的字符: [工智甚能]
   由于本模型是极小字符级模型，输入的每个字都必须在训练语料中出现过。
   您可以输入 ':vocab' 查看支持的所有字，或尝试：'问题：' / '雨停了，'
```

---

## 🔬 进阶参数选项

`chat.py` 也支持从命令行直接传入初始配置：

```bash
# 使用指定权重、长度为 80、温度为 0.5 启动
python chat.py --model result/model.pt --length 80 --temp 0.5
```
