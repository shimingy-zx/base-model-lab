# 项目简介与定位

欢迎来到 **Base Model Lab**（迷你基座模型实验工坊）！

## 🎯 项目初衷

当下，大语言模型（LLM）的讨论铺天盖地。很多人熟悉如何调用 OpenAI / Anthropic 的 API，或者如何使用 HuggingFace `transformers` 库一键加载现成权重，甚至尝试过 LoRA 微调。

然而，**“预训练（Pre-training）基座模型”**到底在发生什么？
- 随机初始化的权重是如何开始第一次前向传播的？
- 字符/词元是如何在注意力掩码（Causal Mask）的限制下计算下一步概率的？
- 所谓的 Next-Token Prediction 究竟是如何通过反向传播让乱码逐渐变成通顺句子的？

为了彻底揭开这些黑盒，**Base Model Lab** 诞生了。它摒弃了一切工业级框架复杂的封装与庞大的依赖，用不到 **100 行纯 PyTorch 代码**，构建了一个端到端、具备全部核心机制的因果 Transformer 语言模型。

---

## 💡 核心设计理念

| 设计点 | 传统预训练实验 | Base Model Lab |
| :--- | :--- | :--- |
| **算力门槛** | 数十至数万张 A100/H100 GPU | 纯 CPU，普通笔记本即可在 30 秒内跑完 |
| **权重来源** | 下载几 GB 到几十 GB 预训练权重 | **0 预训练权重**，参数完全从高斯分布随机初始化 |
| **模型结构** | 几十层 Transformer，数百亿参数 | 单层 Decoder-only Transformer，约 2.7 万参数 |
| **代码体量** | 分布式训练库、巨量依赖、多层抽象 | 单一简洁 Python 文件，逐行清晰可读 |
| **学习目标** | 追求生成指标与泛化分数 | 彻底理解 **数据分词 → 网络前向 → 损失计算 → 梯度更新 → 自回归采样** 的全流程 |

## 📂 项目文件清单

本项目采用清晰扁平的代码结构：

```
base-model-lab/
├── data/              # 训练数据目录
│   └── corpus.txt     # 实验用中文语料文件
├── train.py           # 核心代码：分词器、TinyTransformer、训练循环与采样函数
├── experiment.py      # 自动化预训练脚本：支持命令行调参、导出权重与评估报告
├── sample.py          # 离线快速采样脚本：加载训练好的权重进行文本续写
├── chat.py            # 终端流式交互工具：支持打字机动画、实时调温与指令控制
├── test_train.py      # 单元测试套件：包含因果掩码防未来穿越等关键数学单测
├── result/            # 训练产物目录
│   ├── model.pt       # 训练保存的模型权重 Checkpoint
│   └── result.json    # 训练前后损失、参数量与生成样例记录
└── docs/              # 基于 VitePress 构建的完整技术与原理文档
```

## ⚠️ 认知声明与边界

::: warning 必须明确的实验认知
1. **不能当通用 AI 问答助手使用**：本项目采用约 400 字符的极小语料进行自监督学习，模型参数量仅约 2.7 万。训练完成后，模型本质上是对该微小语料建立了高度精确的转移概率拟合（过拟合与记忆）。
2. **不能处理未见字符（OOV）**：由于采用基于字符的极简分词表，输入提示词如果包含语料中从未出现过的字符，分词器会直接拦截报错。
3. **教学实验定位**：本项目的最大价值是**帮助学习者用最小认知成本、在自己的电脑上运行并亲手拆解预训练的每一行代码与张量形状**。
:::
